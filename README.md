# Harbor & Field Shopify Release Workflow

Shopify CLI release workflow for Harbor & Field, covering local theme workflows, Theme Check, preview links, release approval, and rollback readiness.

Production: https://harbor-field-shopify-workflow.vercel.app

## Scope

- Shopify CLI command awareness
- Local development workflow
- Theme validation and QA readiness
- Release and rollback thinking

## Stack

- HTML and CSS
- Vercel hosting

## Local Operations

```bash
npm run start
```

The workflow board is served as a static operations interface and can be deployed directly through Vercel.
