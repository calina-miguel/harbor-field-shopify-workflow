Harbor & Field Shopify Release Workflow

A practical development workflow board for theme pull, local preview, linting, deploy, and QA handoff.

$ shopify theme pull
$ shopify theme dev --store harbor-field.myshopify.com
$ shopify theme check
$ shopify theme push --unpublished
$ shopify theme share
01

Sync

Pull production theme files into a feature branch before editing.

02

Develop

Run local preview with hot reload and test storefront states.

03

Validate

Run Theme Check and review Liquid, schema, translation, and asset issues.

04

Publish safely

Push as unpublished, share preview links, then promote after approval.
