# Harbor & Field Shopify Release Workflow Specification

## Interface Direction

Harbor & Field needs a concise release-operations board for Shopify theme work. The interface should prioritize command clarity, release sequence, validation status, and handoff readiness for storefront changes.

## Core Screens

- Shopify CLI command transcript panel
- Four-step release workflow board
- Release checklist for theme validation, previews, approval, and rollback
- Responsive layout that remains readable during QA and stakeholder review

## Implementation Notes

- Keep commands readable on narrow screens.
- Maintain form controls with native accessibility behavior.
- Preserve Vercel compatibility with static deployment output.
- Keep repository language operational and organization-facing.
