# Harbor & Field Shopify Release Workflow

Build a professional Shopify release workflow interface for Harbor & Field, an ecommerce operations team managing theme releases. The front-end should present the Shopify CLI workflow, release readiness, QA handoff, and rollback planning in a clear operational dashboard.

Use a responsive React front-end suitable for Vercel deployment. The first screen should show the Harbor & Field release workflow title, a concise workflow summary, and a terminal-style Shopify CLI command panel.

Required features:

- Shopify CLI transcript panel with theme pull, theme dev, theme check, theme push, and preview share commands.
- Four-step release workflow: Sync, Develop, Validate, Publish Safely.
- Release checklist with interactive completion controls.
- Release metadata panel covering preview URL, theme ID, rollback theme ID, reviewer, and target release window.
- QA handoff section covering product, collection, cart, search, checkout-adjacent, and mobile review states.
- Responsive layout for mobile and desktop.
- Accessible controls with visible focus states and semantic structure.

Visual direction:

- Calm operational interface.
- Light neutral background, white work surfaces, deep green/charcoal command areas, and restrained accent colors.
- Dense enough for repeated workflow use without feeling crowded.
- Cards only for workflow steps and checklist modules, with modest radius and clean spacing.
